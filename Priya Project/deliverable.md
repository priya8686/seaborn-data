# Titanic data deliverable\n\nThis repository contains the Titanic exploration deliverable. It includes the notebook, saved plots, and notes to reproduce a PDF presentation.\n\nFiles added/updated:\n- `titanic_exploration.ipynb` — updated notebook with analysis, at least 5 plots and short explanations for each plot.\n- `plots/` — directory where plots (PNG) are saved when running the notebook.\n- `deliverable.md` — this file (summary and next steps).\n\nKey findings (brief):\n- Overall survival: many passengers did not survive; the survival rate is substantially below 50%.\n- Sex: Female passengers had a notably higher survival rate than males.\n- Class: 1st-class passengers had higher survival rates compared to 2nd and 3rd.\n- Age: Younger passengers show a somewhat higher probability of survival; logistic fit visualizes decreasing probability with age.\n- Interaction: Women in higher classes were most likely to survive; men in lower classes were least likely.\n\nHow to export a PDF presentation (suggested):\n1. Install `vscode-pdf` extension in VS Code for quick preview (recommended).\n2. From a terminal with the project's Python environment active, you can export the notebook to PDF via `nbconvert` (requires TeX or an alternate PDF exporter):\n\n```powershell
# Example (requires nbconvert & TeX):
python -m pip install -r requirements.txt
python -m pip install nbconvert
jupyter nbconvert --to pdf titanic_exploration.ipynb --output titanic_presentation.pdf
```
